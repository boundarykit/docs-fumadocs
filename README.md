# BoundaryKit documentation

This Fumadocs portal covers workspace configuration, REST endpoints, webhook events, MCP, boundary configuration, and CI/CD.

Run `npm ci` and `npm run dev` for local editing. Run `npm run build` to generate the static site in `out/`. Serve that directory with a static host that supports directory indexes.

Edit pages and sidebar ordering under `content/docs/`. Both OpenAPI formats and the redirect inventory are at the repository root. Configure legacy redirects on the deployment host.
